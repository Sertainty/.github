## What is UXP?

Sertainty **UXP Technology** protects data at the file level by embedding access controls directly into the data itself — so protection travels with it regardless of location or application.

UXP combines data, access policies, and user credentials into a single encrypted construct called a **Vault**. UXP is the *how*; the Vault is the *what*. The owner defines who can access the data, when, and under what conditions. Those rules are enforced by the Vault itself, without relying on perimeter security or third-party applications.

> **Control stays with the owner at all times** — the data remains protected even against super-user access.

## Current release — Developer v5.0

**Sertainty Developer v5.0** is available now for the developer community. It brings significant upgrades to the platform:

- **Platform hardening** of the patented, proprietary technology
- **FIPS 140-3 validated AES-256 cryptography** (wolfCrypt v5.2.1, CMVP certificate #4718), in a design resistant to quantum and AI-based attacks
- **SDK binaries & libraries** are now third-party code-signed by a trusted CA (previously self-signed)
- **Upgraded licensing security**

Includes core libraries, supported APIs (C and C++), API documentation, basic code examples, the Sertainty Technology Guide and a bundled copy of the Knowledge Base.

## Coming in October 2026

In October the platform expands into three installation kits, available on their own or in bundles.

### Installation kits

| Kit | What it is | For |
| :--- | :--- | :--- |
| **Sertainty TechHub v1.0** | No-code desktop application suite: Identity Studio, Policy Studio, Vault Explorer, Asset Browser | Business and personal users protecting files with the tools they already use |
| **Sertainty Developer v5.1** | SDK: C and C++ libraries, sample code (C, C++, UXL), Sertainty Script | Developers building Sertainty protection into their own applications |
| **Sertainty Server v5.1** | Services: Core, Data, Delegate, Utility and Workflow; Sertainty HTTP Server (encrypted Web API); SQLite or MySQL storage | Administrators running central user management, Vault auditing and automated workflows |

Applications built with the SDK and the TechHub desktop app do not require a server. Server adds services at scale, such as delegates, a central audit registry, and automated workflows including chain of custody.
